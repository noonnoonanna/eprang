자연이 길러주는 나만의 건강 루틴

1분의 설문으로 시작하는 개인 맞춤 모종 구독 서비스
내 생활 패턴에 꼭 맞는 허브와 잎채소를 제안받고, 집에서도 나만의 그린을 만들어보세요.

개인 설문 기반 맞춤 모종 구독

신선한 유러피언 허브·잎채소를 당신의 루틴에 맞춰 제안하고 공급합니다. 단순 배송이 아닌 목표와 생활패턴을 반영한 개인 맞춤형구독입니다.

내 기록으로 완성되는 주간 맞춤 추천

매일 달력에 몸 상태(수면·피로·기분·활동·섭취)를 간단히 체크하면, 일주일 단위로 기록을 정리해 허브·잎채소 루틴을 제안합니다. 복잡한 AI가 아니라, 명시적 규칙과 누적 통계로 투명하게 작동해요.

일별 기록 → 캘린더

2025-10-21, 수면 6h, 피로 상, 활동 보통, 섭취 적음 2025-10-22, 수면 7h, 피로 중, 활동 낮음, 섭취 보통 2025-10-23, 수면 5h, 피로 상, 활동 낮음, 섭취 적음

주간 요약 지표 산출

주간 평균 수면 = 6.2h 피로 지수 = 높음 활동 지수 = 낮음 섭취 균형 = 부족

규칙 기반 추천

IF 피로 지수 높음 AND 섭취 부족 → 추천: 바질, 레몬밤, 버터헤드 사유: 진정·기분균형 + 엽채 보충

결과: 매주 주간 리포트와 함께 추천 조합·섭취 타이밍·간단 레시피를 제공합니다. 사용자는 기록만 남기면 되고, 기준과 사유는 항상 확인할 수 있어요.

모종 중심

기기가 아닌 허브·잎채소 자체에 집중하여 자연 그대로의 웰니스를 전합니다.

데이터 설문

생활습관과 선호도를 반영해 최적의 개인 맞춤 조합을 추천합니다.
